⚙️ Ollama settings

Not connecting?

Windows (Command Prompt):
set OLLAMA_ORIGINS=*
ollama serve

Mac / Linux:
OLLAMA_ORIGINS="*" ollama serve

Quit the Ollama tray app first, keep the window open, and make sure the model is pulled (ollama list). If the browser still blocks it, serve this page with python -m http.server 8000 and open localhost:8000/plant-pal.html.
